# Grupo em números

Site estático que analisa exports `.txt` do WhatsApp inteiramente no navegador. Não faz uploads, não tem base de dados e não envia o conteúdo da conversa a nenhum servidor.

## Uso

Abra `dist/index.html` num navegador ou publique a pasta `dist` como um site estático. Escolha o ficheiro exportado, confirme os nomes dos membros e use **Guardar PDF** para abrir o diálogo do navegador e gravar o relatório em PDF.

## Métricas

Inclui mensagens por membro, hora/dia de atividade, tamanho médio, evolução diária, menções, inícios de conversa (>60 min de silêncio) e tempo médio de resposta. As regras de cálculo aparecem no próprio relatório.
